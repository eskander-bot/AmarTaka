# Amar Taka (by MEskander)

A Bangla-first, offline-first personal finance and expense tracker built with Flutter.

## Features (Phase 1)
- Income & expense tracking with categories
- Monthly balance, income and expense summary
- Recent transactions list
- AMOLED dark + light themes
- 100% offline (SQLite on device)

## Build
Push to GitHub main branch - GitHub Actions builds the APK automatically and attaches it to a Release.
